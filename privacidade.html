Política de Privacidade

Última atualização: 20 de novembro de 2026

O Universo em 60s utiliza um aplicativo próprio, de uso interno, para publicar vídeos nas contas oficiais do próprio canal no YouTube, Instagram e TikTok.

1. Dados acessados

O aplicativo acessa somente as contas do próprio Universo em 60s, com autorização do titular, para enviar vídeos, organizar playlists e responder comentários publicados nesses canais.

2. Dados de terceiros

Não coletamos, vendemos nem compartilhamos dados pessoais de usuários. Comentários públicos são lidos apenas para serem respondidos dentro da própria plataforma.

3. Armazenamento

Os tokens de acesso ficam guardados de forma privada no servidor do canal e podem ser revogados a qualquer momento nas configurações de cada plataforma, incluindo a página de permissões do Google (myaccount.google.com/permissions).

4. Serviços do Google e YouTube

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Este aplicativo usa os Serviços de API do YouTube; ao interagir com ele, aplica-se também a Política de Privacidade do Google.
